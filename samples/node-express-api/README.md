# Tasks API (Node + Express)

A minimal REST API with an in-memory task list. Endpoints: `GET /`, `GET /health`, `GET /api/tasks`, `POST /api/tasks`.
Run it with `npm install` and then `npm start`. It listens on `$PORT`, or 3000 if that is not set. Run `npm test` for the tests, which use the built-in `node:test` runner.

How to host your college project online for free

Students · PBL · Viva7 min readUpdated 25 October 2026

A working live link beats screenshots in every viva, project report and résumé. Here's how to put your college project online for free, even if you've never used Git.

Quick answer
  1. Name your main page index.html, and use relative file paths.
  2. Upload the project to GitHub through the website (no commands needed).
  3. Deploy it on Shipzo from the GitHub link.
  4. Put the link and a QR code in your report and slides.

Step 1: Get your files ready (HTML/CSS/JS projects)

  • Name the main page index.html and keep it in the top folder. Web servers open index.html by default, so a site whose main page is calculator.html shows "not found" at the home address.
  • Use relative paths. <img src="images/logo.png"> works everywhere. <img src="C:\Users\you\Desktop\logo.png"> only works on your laptop.
  • Match capital letters exactly. Windows doesn't care, but servers do: Logo.PNG and logo.png are different files.
  • Open index.html in your browser one last time and click every link and button.
my-project/
├── index.html      ← main page
├── about.html
├── style.css
├── script.js
└── images/
    └── logo.png

Step 2: Upload to GitHub (no commands needed)

  1. Sign in to github.com → click + → New repository.
  2. Give it a name like library-management-system, keep it Public, and click Create repository.
  3. Click uploading an existing file, drag all your project files and folders in, and click Commit changes.

Comfortable with the terminal? Use git init, git add ., git commit and git push instead. Commit history also shows your teacher who contributed what.

Step 3: Deploy it

  1. Create a free Shipzo account (pick "College or school project" when asked).
  2. Click New deployment, paste your GitHub link, and press Deploy.
  3. About a minute later your project is live at https://your-project.shipzo.tech, with HTTPS.

If your project is in a sub-folder of the repo (for example frontend/), set the Root directory in the deployment form.

Step 4: Use the link in your viva and report

  • Report: add a "Deployment" section with the live link, the GitHub link, and one line on how it's hosted (container, HTTPS, CI/CD).
  • Slides: add a QR code of the link so examiners can open it on their phones.
  • Résumé and LinkedIn: list the live link next to each project. Recruiters click links; they don't download ZIP files.
  • Before the viva: open the link on mobile data to check it works outside the college Wi-Fi.
Talking about it in your viva: "Our project is containerized with Docker, deployed through a CI/CD pipeline that runs automated tests, served over HTTPS on its own subdomain, and monitored with automatic restarts." Every part of that sentence is true for apps deployed on Shipzo.

Projects with a database

If your project uses MySQL, MongoDB or PostgreSQL on your laptop (localhost), the deployed version can't reach it. Use a free hosted database (MongoDB Atlas, Neon or Supabase), and put its connection string in your project's Environment variables instead of in the code.

Frequently asked questions

Is this free for students?

Yes. Shipzo is free during the beta, with up to 3 projects per account and no card.

Will the link still work after my viva?

Yes. Apps keep running until you delete them, so the link stays valid in your report and résumé.

Can my whole team manage the project?

Each project belongs to one account. Teammates can push to the GitHub repo, and every push redeploys automatically.

My project is in Java (console app). Can I host it?

Shipzo hosts web apps that answer HTTP requests. A console program needs a web interface first, for example a small Spring Boot or Flask front end.

How to host an HTML, CSS and JavaScript website for free

HTML · CSS · JavaScript5 min readUpdated 21 November 2026

A static website, made of HTML, CSS, JavaScript and images with no server code, is the easiest kind of project to host. You don't need to install anything, and you don't even need Git: a ZIP file is enough.

Quick answer
  1. Put index.html in the top folder (or in public/, site/ or docs/).
  2. Use relative paths like images/logo.png, and match capital letters exactly.
  3. Deploy from GitHub or upload a ZIP of the folder.
  4. The site is served at https://your-site.shipzo.tech by nginx, with compression and HTTPS.

Step 1: Check the folder structure

portfolio/
├── index.html        ← the home page
├── about.html
├── projects.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
    └── profile.jpg

Shipzo looks for index.html at the top of the project, or inside public/, site/ or docs/. If your main page has a different name, such as calculator.html, that's fine too: Shipzo picks the home page by itself, preferring names like home, main or landing and pages that link to the others, and avoiding pages like login or 404. Renaming it to index.html is still the surest option.

Step 2: Fix your paths

  • Use relative paths. <img src="images/profile.jpg"> works everywhere. <img src="C:\Users\you\Desktop\profile.jpg"> only works on your laptop.
  • Match capital letters. Windows treats Profile.JPG and profile.jpg as the same file. Web servers don't.
  • Avoid spaces in file names. my-project.html is safer than my project.html.

Pages also get clean addresses: /about serves about.html, so links can use either form.

Step 3: Deploy it

Option A, from GitHub. Push the folder to a repository, then paste the link into New deployment. Every later push updates the site. The GitHub deployment guide covers this in detail.

Option B, without Git. Zip the folder so that index.html sits at the top level of the ZIP, open New deployment → Upload ZIP (up to 250 MB) and press Deploy. To update the site later, upload a new ZIP from the project's Settings.

Either way, the site goes live at https://your-site.shipzo.tech within a minute. The free Starter plan is plenty, because a static site uses very little memory.

What you get

  • nginx serving your files, with gzip compression for CSS, JavaScript, JSON and SVG
  • An HTTPS certificate issued automatically for your subdomain
  • Uptime checks, and a history of your last five versions that you can roll back to

Common problems and fixes

ProblemFix
Page shows but has no stylingThe path in <link href="..."> is wrong or has different capital letters.
Images are brokenCheck the path and the file name's capital letters, and make sure the image was committed or zipped.
A contact form does nothingA static site can't process form submissions. Use a form service, or add a small backend (see the Flask or Express guides).
Changes don't show upCheck that the new deployment finished, then hard-refresh the browser (Ctrl+Shift+R).

Frequently asked questions

Do I need GitHub?

No. You can upload a ZIP of the folder instead. GitHub is only needed if you want automatic redeploys on every push.

Can I use Bootstrap or Tailwind from a CDN?

Yes. Links to CDNs work exactly as they do on your computer.

Is this good for a portfolio or resume website?

Yes. It is one of the most common uses: you get a free HTTPS address you can put on your resume and LinkedIn.

Is it free?

Yes, during the beta, with up to 3 projects per account and no card.

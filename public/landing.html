How it works

Seven automated stages, every deploy

The same pipeline a DevOps engineer would set up, run for you on every push.

Fetch source

Clone from GitHub, upload a ZIP, or pick a template.

Detect & scan

Finds the stack and scans for committed secrets.

Test

Runs npm test, pytest or go test. Broken code never ships.

Containerize

Writes a Dockerfile and builds an image.

Deploy

Starts the new release with memory and CPU limits.

Health check

Probes the app until it answers.

Go live

Switches traffic with zero downtime.

Features

Everything a small team needs to run a web app

Continuous deployment

Push to GitHub and ShipStack redeploys automatically, through polling or a webhook.

Automated testing

Your test suite runs inside a clean container. Failing tests stop the release.

Docker containers

Every app gets its own isolated container with memory, CPU and process limits.

HTTPS on your own subdomain

Each project is live at name.shipzo.tech with a free certificate issued automatically.

Monitoring & auto-healing

Uptime checks every 10 seconds, response time, CPU and memory. Crashed apps restart on their own.

One-click rollback

The last five releases are kept. Go back to any of them in seconds, without rebuilding.

Supported stacks

Detected automatically

No config files to write. If your repo has its own Dockerfile, ShipStack uses it.

FAQ

Questions

Is it really free?

Yes. During the beta every plan is free, with up to 3 projects per account. We never ask for a card.

What kind of projects can I deploy?

Web apps and websites: static HTML, React/Vite, Next.js, Node/Express, Flask, FastAPI, Django, Streamlit and Go, or anything with a Dockerfile. The app must answer HTTP requests on the port in the PORT environment variable (most frameworks do this already).

Can I deploy a private repository?

Yes. Add a GitHub personal access token with read access when you create the project. It is masked in every log.

My app needs a database or API keys.

Add them as environment variables in the project's Settings. For a database, a free hosted one such as MongoDB Atlas or Neon works well. Shipzo does not host databases yet.

What happens when my app crashes?

ShipStack checks every app every 10 seconds. After three failed checks it restarts the app automatically and records the event in your activity log.

Is this a production service?

Shipzo is a free beta run by a student team. It is great for portfolios, college projects, demos and prototypes. Please do not host anything critical or illegal; see the terms.
